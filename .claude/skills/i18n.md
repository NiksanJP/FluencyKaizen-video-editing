# Internationalization (i18n)

## Domain
Multi-language support for the video production pipeline. The system produces content for Japanese speakers learning English, with extensibility for other language audiences.

## Key Files
- `src/pipeline/types.ts` — `SupportedLanguage` type and `LANGUAGE_CONFIG`
- `src/pipeline/analyze.ts` — Gemini prompt adapted per language
- `style.json` — `fontOverrides` section for per-language fonts

## Supported Languages
| Code | Language | Script | Native Name |
|------|----------|--------|-------------|
| `ja` | Japanese | CJK | 日本語 |
| `zh` | Chinese | CJK | 中文 |
| `ko` | Korean | CJK | 한국어 |
| `es` | Spanish | Latin | Espanol |

## Common Operations
- **Process for specific language:** `bun src/pipeline/index.ts input/video.mp4 --lang ko`
- **Check character limits:** `getLimits(lang)` returns per-language limits
- **Get language config:** `LANGUAGE_CONFIG[lang]` returns name, nativeName, script, categories, titlePattern

## LANGUAGE_CONFIG Structure
```typescript
{
  name: string;           // "Japanese"
  nativeName: string;     // "日本語"
  script: 'cjk' | 'latin';
  categories: string[];   // Vocab card category labels in target language
  titlePattern: string;   // Hook title format pattern
}
```

## Character Limits
- **CJK languages** (ja, zh, ko): 30 characters for hookTitle
- **Latin languages** (es): 50 characters for hookTitle
- Retrieved via `getLimits(lang)` utility function

## Adding a New Language
1. Add language code to `SupportedLanguage` union type in `types.ts`
2. Add configuration entry to `LANGUAGE_CONFIG` in `types.ts`
3. Add font override in `style.json` under `fontOverrides`
4. Update Gemini prompt in `analyze.ts` with language-specific instructions
5. Test with a sample video using `--lang <code>`

## Patterns & Conventions
- Default language is `ja` (Japanese) when no `--lang` flag is provided
- Script type (`cjk` vs `latin`) determines character limits and layout adjustments
- Font overrides in style.json map language codes to font family names
- Gemini prompt is dynamically adjusted based on target language
- Vocab card categories use target language labels (not English)

## Gotchas
- CJK fonts must be installed on the system for correct rendering
- Character limit enforcement happens in post-processing, not in Gemini prompt
- Mixed-language content (EN + target) in subtitles requires careful font fallback
- Some languages may need additional Whisper language hints for accurate transcription
- The `--lang` flag affects Gemini analysis but not Whisper transcription (Whisper auto-detects)
- RTL languages are not currently supported

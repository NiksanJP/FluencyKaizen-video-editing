# Clip Data Loader

## Role
Manages clip data loading, auto-generation of clip registrations, file watching for live updates, and composition registration for Remotion Studio and rendering.

## Owned Files
- `src/remotion/clip-data.ts`
- `src/remotion/clip-data-all.ts`
- `src/remotion/clip-compositions.ts`
- `src/remotion/watch-clip.ts`
- `src/remotion/preview-all.ts`

## Key Functions/Exports
- **clip-data.ts** — Utility functions for loading and parsing individual ClipData JSON files.
- **clip-data-all.ts** — AUTO-GENERATED file that maps clip names to their ClipData objects. Should not be edited manually; regenerated by watch-clip.ts whenever clip.json files change.
- **clip-compositions.ts** — Generates Remotion Composition registrations from the clip data map, creating one composition per clip with correct duration and metadata.
- **watch-clip.ts** — File watcher that monitors `output/` for new or changed clip.json files. On change, regenerates clip-data-all.ts and creates symlinks in `src/remotion/clips/` so Remotion can access clip assets.
- **preview-all.ts** — Composition definition for previewing all available clips in a single Remotion Studio session.

## Common Tasks
- Debugging clip data loading failures (malformed JSON, missing fields)
- Regenerating clip-data-all.ts after manual clip.json edits
- Fixing symlink creation for clip assets in src/remotion/clips/
- Adding new fields to the clip data loading pipeline
- Troubleshooting watch-clip.ts file watcher behavior (missed events, stale data)
- Updating composition registration to handle new ClipData properties

## Collaborators
- **composition-renderer** — Root.tsx imports from clip-data-all.ts to register all compositions; ClipComposition consumes the loaded ClipData
- **schema-validator** — Validates clip.json before it is loaded into the data pipeline
- **pipeline-orchestrator** — Produces the clip.json files in output/ that this agent watches and loads
- **remotion-config** — Pre-render setup in prepare-render.ts ensures clip data is ready before rendering
